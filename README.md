
# 💰 Finance Dashboard

## 📌 Overview

This is a simple and interactive Finance Dashboard built using React.
It helps users track their income, expenses, and overall financial status through a clean and user-friendly interface.

---

## 🚀 Features

### 📊 Dashboard Overview

* Displays Total Balance, Income, and Expenses
* Line chart to show financial trends over time
* Pie chart for category-wise expense breakdown

### 📋 Transactions

* View all transactions in a table
* Search transactions by category
* Add new transactions (Admin only)
* Delete transactions (Admin only)

### 🔐 Role-Based UI

* Viewer: Can only view data
* Admin: Can add and delete transactions
* Role switching using dropdown

### 📈 Insights

* Highest spending category
* Total Income and Expenses
* Financial Status (Saving / Overspending)
* Income vs Expense comparison

---

## 🛠️ Tech Stack

* React.js
* Recharts (for charts)
* JavaScript (ES6)
* CSS (Inline styling)

---

## ⚙️ Setup Instructions

1. Clone the repository:

```bash
git clone https://github.com/MubeenaSayyad/finance-dashboard.git
```

2. Navigate to project folder:

```bash
cd finance-dashboard
```

3. Install dependencies:

```bash
npm install
```

4. Run the project:

```bash
npm start
```

---

## 💡 Approach

* Used React state (useState) to manage transactions, role, and filters
* Implemented role-based UI behavior for Admin and Viewer
* Used Recharts library for dynamic data visualization
* Calculated insights like balance, highest spending category, and comparisons dynamically
